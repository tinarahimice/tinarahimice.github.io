## Design & Frontend Note

I am not a frontend engineer, and UI/UX design is not my core expertise.  
To bridge this gap and focus on what matters most in this portfolio, I used **Figma AI** to assist with the design process.

Figma AI helped me:
- Generate an initial UI structure
- Refine layout and visual hierarchy
- Translate abstract ideas into a clean, presentable interface

This allowed me to:
- Save time on design decisions
- Maintain a professional visual appearance
- Focus my energy on content, logic, and technical depth

I believe using the right tools to compensate for non-core skills is part of effective engineering.
